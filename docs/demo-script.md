# LAKAZ demo script

Target duration is about two minutes, with email verification prepared for a smooth run. Rehearse with a fictional wearer. Check real band events, email login, phone GPS permission and the facility lookup before recording.

| Time | Action and spoken line |
|---|---|
| 0:00–0:30 | Create an account and complete email verification. Open Add a person, enter a fictional name, age and area, and enter band code LKZ-1307. Show the person on Home with no old records. Before recording, Shihad must confirm the demo band is prepared for a fresh run. Account creation alone does not establish that previous band records were cleared. |
| 0:30–1:10 | Double click the button on the band. Show red “Needs help”, tap “I've got it”, and open the acknowledgement receipt. Say “After we drew the Prove It Works card, we added a receipt the carer can open after acknowledging a help alert. We'll refresh Lakaz and reopen the same receipt so you can see the acknowledgement was saved.” Refresh, sign in again if required, and reopen the same receipt. Point to the unchanged server timestamp. Resolve the help alert with “She is safe”. |
| 1:10–1:35 | Walk out carrying the band and phone. Show amber “Left home”. Walk back to the BLE home beacon and show the “back home” banner and “At home since …”. |
| 1:35–1:45 | Open Location. Say “The band has no GPS yet; this phone stands in for it in the demo.” Show the phone’s real position and its update time. |
| 1:45–1:55 | Open Find a health facility. Choose a district and show the official Open Data Mauritius directory and source. |
| 1:55–2:00 | Say “The escalation ladder, community alerts and closed-app push are our roadmap. The corresponding demo screens are sample data.” |

## Fallbacks

If phone GPS has no fix, show that state and its last update time. Do not call a recorded position current. If the physical departure/return fails, describe the intended BLE flow and clearly identify any sample demonstration. If the backend is unavailable, use a recorded successful receipt demonstration and label the recording. The phone GPS integration must be verified on the actual phone before the live pitch.

Fahim tests the APK on a phone when Shihad builds it, records the backup video, and prepares the six-slide pitch deck. Rehearse Add a person and the fresh-record setup against Zuhayr’s latest flow before filming.
